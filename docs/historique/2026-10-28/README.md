# Documentation conservée avant harmonisation

Les sous-dossiers `docs/` et `admin/`, ainsi que les fichiers racine présents ici, conservent les originaux du projet avant l’harmonisation du 28 octobre 2026. Ils peuvent contenir l’ancienne marque, des liens obsolètes et des déclarations de complétude non vérifiées. Ils servent à comprendre l’historique; ils ne pilotent plus le développement.

Le [registre documentaire](../../pilotage/05_REGISTRE_DOCUMENTAIRE.md) indique les éléments retenus et les remplacements. Le [plan actif](../../PLAN_ACTION_GLOBAL.md) est l’entrée de reprise. Les empreintes des originaux sont dans `docs/pilotage/registre_documents.json` depuis la racine du projet.
